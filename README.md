### About the Experiment 

This experiment presents an interactive simulation of the Divide & Conquer Strategies I: Sorting Problem, demonstrating the working of sorting algorithms such as Merge Sort and Quick Sort through step-by-step visualization. It allows users to select the algorithm, choose the input array size, observe the execution through pseudocode highlighting, and analyze decision-making at each step. Additionally, we have incorporated a tree visualization to illustrate how both algorithms operate recursively, helping learners better understand the flow and structure of divide and conquer strategies.
